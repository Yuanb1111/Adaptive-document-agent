# FOURIER interface assets

The combined Chinese / English logo is copied from the original vector paths
on page 6 of the user-supplied *Fourier VI Guidelines V1.0, 2024-06-28*.
Its geometry and colors are unchanged; the SVG includes clear space and no
other contents from the guide. Keep its aspect ratio and original colors.

The interface uses the guide's primary purple (#7A24FD), black, and neutral
surfaces (#F6F7F7, #DBDCDC). Secondary chart colors come from the same guide.
Semantic success/error colors remain distinct, with text identifying status.

Typography requests Roboto and Source Han Sans CN, with Microsoft YaHei / Arial
and system fallbacks. Fonts are not downloaded at runtime, so Local Only does
not acquire external font requests. The preferred fonts must be installed on
the viewer's device to render exactly; licensed font files are not bundled.
