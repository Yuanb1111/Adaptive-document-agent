# Preserve complete meanings and literal column evidence

The affected v139 result had a six-item final briefing and a topic-based
presentation plan, but the independent introduction stopped before its final
review: one selected source part's five meanings were split into thirteen and
rejected by a fixed twelve-meaning capacity. This was a serialization/resource
limit being used as an accidental content gate, not an independent rejection
of the corrected source meaning.

## Meaning count is not a slide count

Per-source meaning-count caps are removed consistently from authored selections,
revision schemas and the source-bound selection validator. No larger arbitrary
count replaces them. Bounded response-token budgets and truncated-output
rejection remain. Every original meaning ID and owning source part must still
be accounted for; empty, duplicate, unsupported and misbound assertions remain
invalid. The revised selection still needs independent full-source/union review
and complete visible-copy coverage for every meaning, including index twelve
and beyond. Existing digest/reuse checks cover the full list.

The body limit remains twenty slides, introduction at most five, with Data
Index counted separately and analysis continuation pages counted in the body.
Increasing the number of individually checked meanings does not add pages or
permit an unverified introduction.

## Conflicts caused by derived column metadata

The affected result also contained nineteen conflict groups involving sixty-four
observations. None of those IDs was used in its selected presentation topics,
charts, calculations, insights or presentation plan. The conflict checker was
correctly detecting collisions in derived records: broad caption years overrode
explicit column years; unrelated percentage annotations contaminated units;
distinct growth intervals or headerless amount/share columns collapsed to the
same derived identity. The literal source values themselves were not changed.

Header handling must use direct column evidence, with explicit aligned period
headers taking precedence over a title's date range. Unrelated outer annotations
must not assign units to numerical columns. A blank cell may share a period only
through a retained literal source span; adjacency alone cannot establish it.
Existing amount, percentage, count and interim-period tiers remain available.
If literal source geometry does not
establish a column's period or measure role, preserve the raw table and report
ambiguous analytical alignment rather than inventing metadata. Explicitly
different source captions cannot establish a continuation merely because their
derived generic headers match. The conflict checker and selected-evidence gates
are retained.

Unresolved header diagnostics are carried into the report and downloaded
validation warnings, including after table serialization and reporting retry.
Quarantined analytical rows cannot yield observations or lend their scope to a
continuation; their original source grids, spans, values and page evidence remain
available. Existing presentation QA continues to block ambiguous selected
evidence while reporting unused ambiguous tables as warnings.

The extraction cache version changes to `extraction-v19` so new runs cannot reuse
the older derived table/observation contract. Saved JSON keeps its original
version and source evidence. Offline replay does not certify a fresh model
review or a completed real-model PowerPoint export.
