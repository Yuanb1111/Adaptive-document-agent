# Meaning-complete introduction copy and bounded reporting shutdown

The retained `.584` v143 run finished partial after 21 minutes 19 seconds. Its
independent audience selection and meaning revision succeeded. The later copy
coverage review failed: the final paragraph omitted two required product
qualifications. Earlier reviews had treated those qualifications as implied;
the final review found the omissions after both ordinary meaning corrections
were already consumed. A shared paragraph changed for other source parts, so
freshly reviewing its source bindings was appropriate.

The selected inventory contained 55 required meanings. The initial author also
received a 350-word synthesis instruction and optional-number guidance, despite
the accepted inventory already establishing which assertions were necessary.
Its 349-word draft omitted required meaning. Readability guidance must not
override the independently approved semantic contract.

The writer now identifies every selected meaning by its exact source part and
zero-based index, with a literal quotation from the current paragraph. These
references are checked again after deduplication and pagination. The flat author
index does not duplicate owned passages: complete quotations remain in the
original source catalog. Changed copy must update its own references.

Selected introductions receive a fresh complete semantic coverage review on
each round. Progress uses exact missing-meaning identities rather than counts of
failed paragraphs. After the ordinary correction budget, one additional pure
omission correction requires an independent authorization: every earlier
reported deficit must already be covered, every new deficit must be genuinely
missing rather than contradictory, and the opening/identity must remain valid.
That authorization does not approve the final copy. The addition still needs a
fresh full review and cannot trigger a layout rewrite or another source repair
that changes protected text. There are at most six candidates, two source
corrections and three meaning corrections, with the last meaning correction
reserved for this single late-omission path.

The same run continued briefing requests for roughly three minutes after the
mandatory introduction had failed. Those requests could not produce a complete
presentation. Failure checks must apply before new editorial work, including
requests queued during a parallel introduction, without changing the gateway
state shared with other runs.

The dependent gateway view checks the invocation's introduction before requests,
again at queued request admission, and before format repair. The original
gateway remains unchanged and the introduction uses it directly. Failure
checkpoints merge local and snapshot diagnostics before draining workers, so an
early stop cannot lose already recorded plan errors or completed body content.

## Invariants

- Python validates exact meaning identifiers, literal visible quotation spans,
  source ownership, calculations and physical page limits. A model still decides
  semantic coverage; an author-supplied mapping is not independent acceptance.
- Previously approved wording cannot authorize a changed paragraph. The current
  source, required meanings and visible copy must pass independent review.
- A new omission can receive only a bounded correction after earlier reported
  deficits are verified as covered. Contradictions, unsupported claims and
  unresolved earlier failures must not be relabelled as new omissions.
- A failed introduction preserves extracted evidence, calculations and completed
  report artifacts. It prevents new optional editorial requests; an already
  admitted provider request remains subject to its existing timeout policy.
- Privacy and explicit cancellation keep their existing exception semantics.
  Local Only does not gain a cloud fallback.
- Introduction slides remain capped at five and body slides at twenty. Data
  Index remains separately counted; analysis continuation slides count as body.
  No setting or document-type-specific workflow is introduced.

## Replay integrity

External analysis JSON and the matching PDF remain read-only and outside the
repository. Actual recorded provider responses, saved validated artifacts,
synthetic protocol adaptations and unavailable future replies must be labelled
separately. A missing newly required response must stop the real checkpoint
replay; it cannot be replaced by fabricated semantic approval.

Separate synthetic complete-report tests exercise successful correction and
native PPT export, as well as strict rejection and early shutdown. Their model
replies are controlled fixtures, not a guarantee of the next real model run.

## Validation

The actual `.584` whole-report resume passed in 195.82 seconds with the real PDF
hash and retained-analysis guards. Its original JSON, PDF, 1,623 observations and
five calculation results were unchanged. All 55 selected meanings survived;
historical literal review quotes supplied 43 author-reference adaptations, while
the twelve historically missing meanings remained unmapped. The new coverage
gate required a new correction response, which the retained run did not contain.
The result therefore stayed partial and issued no briefing request.

Two synthetic successful reporting flows (deferred and background introduction)
completed the late-omission path, exported native PPT files, reopened them and
checked the corrected qualifications in actual introduction text. Five negative
flows retained evidence and nonempty calculations while blocking export and
further dependent work.

The initial repository-wide run reported 4,050 passed, five failed and thirteen
skipped. The five failures exposed legacy expectations that briefing continued
after missing introduction, an early-stop diagnostics merge omission, and a
default-field fixture mismatch. These were corrected. The final 73-file affected
suite passed 1,079 tests with five optional external-record tests skipped; the
new `.584` external test was separately enabled and passed. The remaining four
optional cases were not claimed as new external replays. Final collection found
4,107 tests, including the subsequently added coverage and late-omission cases.
