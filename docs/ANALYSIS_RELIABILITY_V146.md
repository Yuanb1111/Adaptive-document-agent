# Source context and bounded agent recovery

The retained v145 `.233` run completed, but its reporting path lost a comparison
period across coordinated clauses, attached an unrelated missing-data row to a
total, and removed useful findings whose quoted data rows lacked their literal
table headers. The separate `.111` run stopped before candidate scoring because
its introduction reader could not resolve a short cross-reference and relocated
running headers on rotated source pages.

These are agent and evidence-contract failures. The changes contain no issuer,
prospectus, page-number, metric-name or document-type workflow branches.

## Evidence and recovery

- Direction validation retains one explicit comparison range across coordinated
  clauses in the same sentence. A clause's own period wins. Conflicting ranges,
  incomplete endpoints and shared predicates with conflicting metric directions
  require semantic correction rather than a destructive word substitution.
- Missing-data measure cells cannot create a section heading. Explicit named
  totals do not inherit unrelated section names. Source rows and raw values stay
  intact; missing values do not become zeroes.
- Literal compound units are recognized before monetary keywords. Numerator and
  denominator scales remain separate; currency in a denominator does not make
  the observation a currency amount. Unknown dimensions retain raw display
  evidence but have no normalized numeric value and cannot enter calculations.
- A complete, ordered, unambiguous quoted table row can acquire its own literal
  source header, within the existing excerpt and quotation limits. Partial rows,
  ambiguous tables, missing headers and discontinuous excerpts cannot acquire
  inferred dates or units. Header binding is audited and grants no semantic
  acceptance; the independent source and meaning reviews remain mandatory.
- Assurance annotations remain tied to their original reporting columns. The
  reviewer and targeted meaning correction receive the same verified column
  inventory; a final guard rejects explicit audit-status assertions without
  period-bound support. Missing or conflicting geometry remains unknown, rather
  than becoming audited or unaudited. Independently cited affirmative source
  prose can qualify its own complete period; negated or uncertain prose and
  flattened table headers cannot manufacture that support.
- Running-layout proof considers each line's retained geometry and repeated
  aligned margins, independently of extracted reading order. Proving a footer
  cannot dispose of adjacent prose or a disclaimer. A still-rejected short
  layout range has one additional bounded model reread. Only the model can
  choose content; a literal internal fallback still requires the independent
  slide editor before publication. Current errors describe the latest verdict,
  while prior failed responses remain in the audit.

## Reporting

Whole authored introduction paragraphs are balanced among equally short valid
paginations without changing copy, source bindings, order or theme boundaries.
Topic and briefing prompts ask the model to assess complementary rates and
levels, and explained reconciliations, rather than automatically dismiss them
as duplicates. These instructions do not force any particular analytical topic.

Audience closing pages use concise source-coverage limitations with affected
pages. Original review questions and decisions remain in speaker notes and the
analysis audit. Failed supplementary source checks are disclosed too. The table
of contents follows native body-before-appendix order. Date charts anchor ticks
to an observed source date and show the exact final date on narrow charts;
editable workbook dates and point values are preserved.

Extraction and analysis contracts advance to `extraction-v20` and `analysis-v75`.
The reporting version is `2026-10-16-source-context-and-agent-validation-v146`.
Older affected checkpoints therefore cannot silently supply stale results.

## Validation scope

The source PDFs, downloaded JSON, generated previews and live-call audits remain
outside this repository. Offline regression tests use synthetic evidence and
retained response replays. A retained bad reply is never described as a fresh
independent acceptance.

All 4,311 currently collected Python tests are accounted for by the complete
suite and subsequent focused reruns: 4,297 passed and 14 conditionally skipped.
The complete run initially had eight subprocess dependency failures because
temporary dependency paths were not inherited by child interpreters. All eight
passed in an isolated local virtual environment; no production change was made
to satisfy that environment issue. Newly added source-binding cases were rerun
after the final code changes. The 19 notification/progress JavaScript tests
also passed. Conditional real-renderer and external-fixture skips do not certify
cloud rendering or a complete live document run.

With the user's explicit authorization, `.111` replays its original three
responses and sends only the previously failed pages 18–21 context through the
configured `LLMGateway` for one fresh bounded reread. It completes reading with
28 bound parts and no current reading errors. This verifies the former blocker,
not the complete downstream analysis of its 558 pages.

The `.233` live check is a fresh executive briefing with independent source and
meaning review, limited to ten authorized original pages. It is not a complete
document rerun. The first live check exposed an incorrect attribution of a
column-specific audit marker; its acceptance is retained as a failed factual
checkpoint. The new guard rejects those erroneous qualifications. A subsequent
fresh run generated seven findings in four gateway calls, passed source and
independent meaning checks, and did not repeat the invented qualification.
It retained the cash-flow and inventory-risk findings after supplying their
literal headers. This is evidence for the repaired boundaries, not a guarantee
of completeness or full-document narrative quality.

A local native PowerPoint preview was rendered to inspect chart dates, direction
copy, source limitations and agenda order. It reuses historical authored content
and is a regression preview, not a replacement final report. Full-document
