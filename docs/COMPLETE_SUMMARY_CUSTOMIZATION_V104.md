## Contracts

- `language_scope` distinguishes body, source tables and an explicitly global
  request. Localization excludes literal original table cells, unit/qualification
  labels and source section names. Chart display caches can be translated while
  embedded original Excel data remains unchanged. Translation review and numeric
  preservation gates still apply.
- `SectionBindings` returns only table IDs, source ranges and resolution. Python
  copies validated bindings onto the original requirements. Independent language,
  focus and detail intent cannot be rewritten by the navigation step. Every table
  ID must appear exactly once; source headings and boundaries remain verified.
- Complete introductory reading requires a supported fact for each substantive
  part. Standalone headings and layout remain separately audited. Every content
  part must appear in the introduction, including constraints and qualifications.
  Later analytical coverage is not an omission reason. Planning is bounded to
  twelve content parts and about 24,000 serialized characters per batch, with no
  eight-page cap on the combined introduction. All parts and decisions receive a
  final global coverage check. No document-type topic checklist is introduced.
- Introductory source quotes can span up to 6,000 characters when necessary for
  complete table headers and rows. Literal adjacent chunks retain every word and
  pass the original brief evidence checks. Only an exact cited negative table
  coefficient authorizes bare accounting parentheses as a negative claim.
- Native introductory body shapes carry durable item/part bindings. Export checks
  verify the complete visible source or reviewed translation for every item and
  every substantive part. Speaker notes alone cannot satisfy coverage. These
  bodies cannot be removed by sparse-page folding.
- Comparative briefing copy receives source-bound model review. The model owns
  semantics, metric associations and reporting-period interpretation; Python
  checks declared numeric direction and duration compatibility. Rejected claims
  enter the existing bounded item patch workflow, and repaired/salvaged claims
  must pass review again. Unchanged items reuse only a run-local review memo.
- Percentage restoration cannot treat a cited year row or Chinese calendar year
  as a percentage. Supported Chinese per-unit spelling retains the original
  denominator; an omitted denominator still fails validation.
- Resolved point-date records with overlapping dates may share one sparse matrix.
  Missing retained cells show an explicitly explained dash, not an invented value.
  This prevents a nearly empty one-row continuation without shrinking the type.
