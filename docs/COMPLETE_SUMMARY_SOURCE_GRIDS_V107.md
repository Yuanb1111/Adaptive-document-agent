# Complete Summary and source grids (v107)

The v106 customized and default runs both lost the company introduction after
reading failures. The customized run also rejected faithful Chinese display
spellings and missed source tables with unconventional labels or headers.

## Reading and introduction

Internal reading facts can retain up to 6,000 characters; published introductory
items still have their separate 180-character limit. This prevents long risk or
conditional passages from failing the reading schema before editorial planning.

One source-bound correction remains available. If its numerical paraphrase still
fails, the reader retains the model-selected literal source lines as an internal
extract, with the rejected paraphrase and exact errors recorded in the audit.
It does not publish that paraphrase or manufacture a summary. The editor must
write supported copy from the selected extract; published copy still passes the
normal numerical, currency, unit, period and source checks.

An ordinary failed reading batch no longer cancels the other independent batches.
Privacy failures and user cancellation still stop subsequent work. Complete line
coverage remains mandatory, as does an included slide item for every substantive
part. Neither heading nor layout classification can hide a long body passage.
The default run uses this same introduction workflow without a customization
prompt.

## Chinese display copy

The validator accepts equivalent month precision, signs before currency names,
explicit Chinese percentage-decline wording and bare period labels such as 6M.
It continues to reject an invented day, reversed direction, changed currency,
scale, period, value or missing repeated number. An independent model review
still checks meaning and requested language.

Native chart labels wrapped after translation inventory capture can reuse only
an unambiguous translation with exactly equivalent whitespace. Fuzzy string
matching is not permitted. Original table cells, source context and chart
workbooks remain literal.

## Source appendix

A separate geometry-based recovery retains repeated aligned source grids without
requiring a conventional year header or numeric-only value cells. It keeps these
grids out of analytical observations when column meaning is unresolved. Numeric
scenario prices remain part of their label column; they do not shift data cells.
Repeated heading tiers are not accepted as independent tables.

Leading rows misclassified as header context are joined back to their evidenced
physical fragment. Original header qualifiers such as `(decrease)` survive
geometric header reconstruction. Native editable grids continue to paginate and
verify every retained coordinate. Existing word geometry is reused when present.

An oversized, complete executive briefing can request one model selection of
2–7 original candidates before locks are established. Python does not choose
which findings matter. Selected claims then pass the existing evidence and
meaning checks, and any item repair cannot alter verified locks. Truncated or
malformed envelopes remain rejected.
