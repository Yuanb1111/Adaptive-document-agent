# Coverage and presentation recovery (v158)

PPT83 and analysis `.875` completed on v157, but their presentation still needed
review. All 489 deferred series had a delta decision; 160 provisional inclusions
exceeded the final synthesis context. An incorrect inventory series reference also
removed a selected topic. Two supplementary source reads failed, while periodless
water/emission columns generated apparent conflicts. A four-measure comparison
was split into three charts and a sparse continuation.

## Recovery contracts

- Oversized complete-fact synthesis first receives up to three levels of bounded
  model-owned proposal reduction. Every requested series keeps all ordered raw and
  normalized points, source scope and qualifications. Python partitions by size;
  the model decides importance and records every omission. Original accepted
  evidence is immutable. The existing global model-call bound still applies.
  A failed reduction or invalid final merge commits no provisional changes and
  remains visibly unresolved.
- Unknown topic IDs receive one model-owned reference repair against a complete,
  losslessly encoded catalog. Valid IDs cannot change. Unknown targets, duplicates
  and ambiguous/unbound references remain invalid; all ordinary claim, period and
  source checks still run. No fuzzy ID substitution is used.
- Supplementary reading allows two semantic reads and one separate,
  content-preserving format repair per target. One selection and two targets cost
  at most seven logical calls, with 2048 output tokens per read/format repair.
  Raw rejected responses, validation causes and attempts are retained in the
  exported source coverage ledger. Truncation/transport/privacy failures do not
  become negative source findings or cloud fallback.
- A bounded model review can remove a caveat only when its entire meaning is
  already covered by an owned literal source note displayed with the evidence.
  Additional conditions remain. Malformed verdicts leave all caveats intact.

## Extraction and display

Attached year-note markers are accepted only by the header tier syntax test; raw
headers and their geometry survive. Annual/interim assignment still requires the
existing source scope/geometry proof. Small adjacent overlapping subscript letters
stay with their literal labels; unrelated floating glyphs do not merge.

Four to six compatible selected measures from a common source table can use one
complete editable table, including in cached plans. Negative values remain signed.
Uniquely source-bound dashes/N/A are copied literally, never converted to zero;
unbound cells are distinguished from source placeholders. Notes retain all source
records. The model still selects which measures belong together.

Neutral authored topic names label chapters and chart pages, while directional
takeaways stay in their own copy. A missing analytical page is described separately
from independently verified conclusion findings. Source-note and caveat review
does not manufacture source coverage or suppress incomplete-review notices.

## Validation and migration

Regression tests cover successful reduction and fail-closed capacity behavior,
catalog binding boundaries, source quote/format recovery and call bounds,
annotated year tiers, subscript geometry, source placeholders, table eligibility,
chapter labels and caveat ownership. Local replay of `.875` checks native export
and rendered layout without changing its observations, analysis results, topic
selection or recorded model usage. A replay does not certify a new live model run
or complete the historical failed supplementary/coverage reviews.
