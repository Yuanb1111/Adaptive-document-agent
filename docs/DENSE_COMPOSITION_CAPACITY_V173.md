# Dense composition capacity recovery

A composition with several long category labels could fail at
`presentation_budget` even after its multi-chart page was split. The remaining
single-chart retry moved the heading into commentary but reserved a fixed side
column. Legend wrapping still left too little space for a readable plot, so
physical budget measurement stopped before the model could review page costs.

The final bounded retry now gives that chart the full content width. It retains
source definitions and limitations beside the plot, avoids a duplicate chart
heading when the page already has the same title, and places the fixed Share (%)
unit beside the complete change annotation. Supporting facts and commentary use
the existing continuation mechanism. Every failed attempt is rolled back.

The minimum readable plot dimensions are unchanged. Categories, periods, values,
evidence and the model's content selection are unchanged. A chart that still
cannot fit fails rather than clipping source qualifications. Continuation pages
remain subject to the ordinary body and analysis budgets; this recovery does not
mark incomplete source review, localization or budget selection as complete.

Regression coverage includes a real eight-category matrix with long labels,
complete supporting-table continuation, preserved commentary and source context,
unit/annotation separation, native chart values after save/reopen, and rollback
when a chart genuinely cannot fit.

Report recovery also exposed an independent review truncated at its output
limit. Previously that error retained an unresolved warning but allowed the
analysis to be marked complete. Source drafting and independent review now each
allow one capacity retry (8192 then 16384 tokens), only when the gateway confirms
length truncation. The retry uses the same complete messages. Partial JSON stays
in the local audit and is never continued or sent as evidence to the reviewer.

The pipeline distinguishes readiness to enter final reporting from completed
source integration. All supplementary checks need a fresh accepted decision
bound to the current evidence, brief and topics. Unresolved review returns a
reporting checkpoint with failed stage `source_integration`; cached complete
flags cannot bypass the same gate during PowerPoint export. Private page-budget
measurement remains available before review. Regression tests cover bounded
recovery, stale verdicts, failure classification and the export boundary.

Visual inspection also found a briefing label that asserted the opposite trend
to its body. The independent meaning review now explicitly judges labels as
audience claims against the same metric, periods and evidence as their body.
Numeric comparisons can bind a contiguous claim in either field; they cannot
join text across fields. Existing source-bound arithmetic and qualification
checks apply equally to label claims, including literal reported changes.
