# Quantity notation, targeted repair and independent page budgets

The .073 diagnostic ran v127. Its first introduction theme was blocked on an
explicit count of one: the cited passage used the indefinite singular `a model`,
while the draft used `one ... model`. Both targeted repairs retained the same
copy and fact IDs. A later theme exposed a second notation problem: a monetary
range with a shared scale and per-unit denominator was checked as though its
first endpoint had no unit.

## General Agent changes

- Validation-only notation accepts a source indefinite singular as lexical one,
  with noun meaning and scope still subject to independent semantic review.
  Indefinite plural/aggregate phrases confer no count. An ordinary authored
  article is not treated as an additional numerical claim.
- Explicit monetary range notation shares only its stated currency, magnitude
  and denominator with both endpoints. Each endpoint must pass existing source,
  sign and unit checks. Source passages and authored copy remain unchanged.
- Complete ordered table rows can retain a single layout leader dot between
  their exact label and cells. This does not bridge omitted words, change signs,
  infer missing units or authorize incomplete rows.
- A complete explicit denominator can end before `and`/`or` and a quantified
  next item. Every following amount still needs its own source unit; the prior
  amount cannot lend it a denominator.
- An unchanged source repair receives one final addressed protocol correction.
  Repeated non-progress remains a visible failure; no validator is disabled.
- If an initial meaning patch clears its old failures but creates at least as
  many new omissions, one final additive correction locks existing copy and
  titles. All additions remain source-bound and independently reviewed. This
  does not permit repeated rewrites or a third meaning correction.
- A Brief worker invalidated only by final presentation-topic corrections is
  regenerated once against those final topics. Changes to source data, document,
  purpose or analytical inputs still fail closed. Fresh source and independent
  meaning checks remain mandatory.
- Brief quantity repair and newly exposed meaning failures have separate
  bounded corrections. Only a fully source-valid, topic-covered patch can enter
  the final meaning correction. Accepted findings stay immutable; the final
  patch again requires source and independent meaning checks. Purely semantic
  initial failures do not acquire an extra repair loop.
- The final Brief meaning patch edits text only. Labels, citations and existing
  source quantities stay locked; it cannot enumerate additional table values.
  Magnitude annotations are retained only for quantities still displayed.
  One format correction preserves the exact source and targeted schema.
- A model can identify an actual reported percentage comparison separately from
  a period flow total. Both endpoint percentages must be explicit in the claim
  and supported by literal source percentage units. Arithmetic and source/meaning
  checks remain mandatory; ordinary flow totals still require matching durations.
- A section slide limit is distinct from a whole-report limit. Intent parsing
  preserves both constraints and the user's appendix scope. Introduction
  synthesis receives its explicit section limit; later evidence coverage review
  and every correction retain the trusted report instructions and full source
  context. Full reading and review remain independent of audience page count.
- Actual exported native slides are counted for report and introduction scopes.
  Appendix exclusion requires durable appendix placement. Over-budget output
  cannot become a verified export, including through the legacy financial force
  flag. No evidence is deleted or silently relabeled to conceal excess.

The changes contain no issuer, industry, PDF filename, rejected-number whitelist
or document-type branch. Generic fixtures cover several nouns, budgets, ordinary
articles, amount ranges, sign changes, wrong units and non-progressing repairs.
Raw documents, local diagnostics, provider configuration and generated artifacts
are excluded from Git.
