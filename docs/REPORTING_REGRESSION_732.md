# Reporting recovery from diagnostic .732

The recorded selection failed on a schema-forbidden `null` placeholder. Live
reporting retries then exposed several independent evidence and correction
failures. The changes preserve source pages, extracted observations and Python
calculation results; they do not waive publication review.

- The gateway can remove a forbidden null field only when every schema error is
  of that type. Duplicate JSON keys, non-null extra values, missing required
  fields and truncated responses remain failures. The repair records removed
  paths and does not require a second model request.
- An explicitly calculated CAGR may bind to the Python calculation catalog only
  for its exact interval and value. Fiscal labels remain distinct. Unsupported
  percentages now produce actionable diagnostics. Page revisions receive their
  actual bound calculations, and unchanged selections keep their draft for
  targeted correction and fresh review.
- Supplementary writers and reviewers receive the same original line positions
  in reading orientation. A conservative geometric check can bind the first
  adjacent bare amount beneath an explicit currency/scale header. Ambiguous,
  displaced, missing or unquoted evidence grants no unit. The model must still
  decide the amount's measure and project ownership from the source.
- Targeted source revisions receive an explicit map from merged item keys to
  current items and owning sections. Length-only corrections receive only their
  own original text and locked evidence, preventing unrelated sibling context
  from supplying new facts. Every merged proposal still passes numerical and
  independent semantic checks.
  Items with locked magnitude annotations or comparison tables are not split
  during length repair. Old objections do not discard a newer valid proposal
  that has not yet received its independent review.
  Numerical correction stays within those same addressed items. Copy-only
  compression follows the configured reduced-reasoning policy and can retry a
  proven output truncation once with identical input and a larger output budget;
  partial JSON is never accepted. Source review keeps provider-default reasoning.
  If a mixed schema correction fixes every non-length error and strictly shortens
  every remaining overlong field, the existing one-time length-progress slot can
  compress those fields. Unchanged or newly overlong fields receive no extra retry.
  Source additions must quote the continuation containing each asserted target
  and preserve complete year labels; missing evidence still blocks completion.
- Physical page references in a brief use the existing citation checker: every
  page in a cited range must belong to that item's quotations. A reference is
  masked only in the numeric validation view; its digits never authorize an
  amount elsewhere. Display copy and literal quotations remain unchanged.
- Native commentary boxes expose their measured occupied height instead of
  reserving empty space after a sentence-boundary cut. Single-chart pages use
  the existing lossless continuation-packing checks, including a chart-column
  alternative when a full-width band would overlap a fixed sidebar. Fonts,
  complete paragraphs, citations, values and minimum chart dimensions remain
  unchanged; the original continuation survives if no checked placement fits.
- A fresh final source-review rejection reaches the existing bounded retained
  page-correction route instead of resuming the same rejected plan unchanged.
  Review and writing share the same eligible-value boundary: material source-only
  qualifications retain their qualitative meaning, while unsupported numbers,
  misleading reassurance and comparisons across incompatible periods are rejected.
  Local revisions receive the related pages already supplied to selection review,
  not just the flagged finding's primary table. Source-authored pages may retain
  literal `context_evidence` quotations for qualitative limitations; those exact
  supplied pages enter slide and theme citations. They never expand eligible
  numeric inputs. Both compilation and later plan validation recheck quotation
  text and source fingerprints, and the independent review still decides meaning.
  A source-defined named interval remains distinct from a chart's narrower
  comparison interval and cannot silently inherit that interval.
  Local corrections also retain earlier review questions for the same addressed
  page, so a new correction does not silently erase an earlier qualification.
  These questions remain fallible feedback, never evidence or approval.
- Brief corrections retain each newly introduced companion measure's own period
  and assurance scope. Ambiguous negated comparisons remain rejected; feedback
  asks for a source-supported strict comparison or independently dated facts,
  rather than allowing the source reviewer to discard their comparison ledger.

Private source diagnostics, model responses and rendered validation artifacts
are excluded from Git. `ADA_SELECTION_DIAGNOSTIC` optionally enables local
regressions using the original .732 JSON. The reporting deadline and correction
budgets are unchanged.
