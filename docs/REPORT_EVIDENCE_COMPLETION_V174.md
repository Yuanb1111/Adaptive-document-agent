# v174 report evidence and completion

Conclusions can state the opposite of a correctly calculated change if the semantic
review silently substitutes a direction different from the original wording. A
separate source-blind review now reads the exact title/body claim and classifies
its direction and signed/absolute-value basis. Python cross-checks that result
against the source-bound calculation. Rejected wording goes through the existing
bounded item repair; only a passing pair of reviews is memoized.
The source-blind predicate classifier uses the configured simple-task reasoning
policy, just like the existing meaning review. Provider-default opt-out and exact
endpoint/model capability checks remain in force. Only newly classified operations'
request-policy identities change, so unrelated completed request caches remain reusable. An explicit
provider output-length finish permits one retry from 8,192 to 16,384 tokens with
the identical complete audience text and prompt. Truncated output is diagnostic
only, and exhausted capacity never becomes a format correction. A complete
format/index failure still has one separate bounded correction; transport,
privacy and cancellation errors propagate without a content retry.
If that independent review exposes only missing or non-directional comparison
bindings, the source reviewer has one correction opportunity before audience copy
is repaired. The original copy and complete evidence remain fixed, and the proposed
bindings must pass all source, arithmetic, duration and assurance checks followed
by a fresh source-blind direction review. Genuine direction or magnitude conflicts
are not eligible for this correction. Forecasts or persistent conditions do not
become invented numeric trends; their full meaning still requires source review.

Coverage batches retain a complete include/omit ledger. A complete final merge
that exceeds the topic or display-omission schema gets one source-aware correction
using the same evidence. The model must regroup or explicitly justify omissions;
Python never truncates topics, evidence or decisions. Transport and truncated
responses do not become semantic approval. Incomplete or stale coverage blocks
completion and public PowerPoint export while retaining a reporting retry
checkpoint. Internal deck measurement remains available before final review.

Report audit-scope review links an exact observation to its entity, metric,
period, raw amount, unit, scale and assurance evidence, followed by an independent
review. Bindings are separate report metadata; extraction and calculations stay
unchanged. Assurance for amounts cannot silently transfer to ratios or adjusted
measures. New or changed retained scope requires a current review.
Before binding review, the gateway selects additional counterpart sources from
the complete existing section and physical-page navigation index, retained target
identities and source-check context. Navigation previews and literal raw-value
hits are clues only; unselected page bodies are not sent. Each selected range is
validated against its indexed section and read in full, including headers and
page labels. At most four ranges of three pages are added, and the combined
evidence must fit 150,000 characters without truncating pages. Invalid selections
receive one correction; unresolved boundaries or capacity failures retain a
reporting retry checkpoint. The complete document text is hashed locally so
source changes invalidate both selection requests and audit approval, even when
their navigation previews are unchanged. A newly expanded context invalidates
all prior dispositions, including unknowns; source discovery is not assurance
approval or a declaration that the entire document was reviewed.
This navigation operation follows the configured simple-task reasoning policy,
as the existing source-page selector does; substantive assurance drafting and
independent review retain their separate policy. Provider opt-out and verified
endpoint/model capability checks remain unchanged.
The review uses batches of at most three observations, with all source pages kept
in each request. A complete independently accepted disposition is required for
every observation before the combined review can pass. A failed batch leaves a
retry checkpoint; only completed batches with the same source fingerprint can
be reused. This prevents a larger topic selection from exhausting one request's
reasoning capacity while preserving the full evidence and final completion gate.
Only a proven output-length truncation permits binary subdivision down to a single
target; all source pages and the fixed per-request limits remain intact. At most
two independent source groups run concurrently through the existing gateway.
Failure cancels queued requests and drains active calls before saving the record.
Completed batches and proven subdivisions that were not reached during a later
failed retry remain available, after their exact source bindings are revalidated.
Binding validation collects every independent failure in a complete draft before
the existing bounded correction. Feedback identifies the observation and exact
field (for example, an incorrect target-source page and a value quotation missing
its metric label), so one correction can address both without weakening literal
evidence, period, entity, unit or amount checks. Invalid drafts never reach the
independent semantic reviewer. Source-binding validation and independent semantic
review each have one correction opportunity, with at most three drafts in total.
A second failure of either kind exhausts its budget and fails the batch; transport,
privacy, cancellation and output-capacity handling retain their separate rules.
The review verdict ledger covers only proposed bindings, never unresolved IDs;
an all-unknown draft requires an empty verdict list and a separate explicit review
of its unknown dispositions. Complete reviewer format errors or duplicate,
missing or extra verdict IDs use that same independent-review correction slot to
correct the reviewer response against the unchanged draft and complete sources.
They do not regenerate the writer. A later semantic rejection cannot borrow
another correction, and extra verdicts are never silently dropped. Original
invalid responses and all physical output attempts remain in the audit record.
Correction feedback also restates the complete target-page, row-label and raw-value
contract, so fixing a page number cannot silently replace the retained source row
with a nearby title or prose paragraph.
Independent-review feedback remains an opinion to verify against the full original
sources, not new evidence or authority to flip an assurance status. A shared entity
or year, a matching total, or an uncertain unaudited marker cannot establish the
status of a detail line. A corrected binding still needs the complete exact-measure
and assurance-scope chain; otherwise it remains unknown and requires independent
acceptance of that disposition.
Writer and reviewer quote instructions permit omitting only typographic table dot
leaders under the existing literal normalization. All words, values, decimal
points, signs, symbols and units remain required; source pages are not shortened.

An accepted assurance verdict now carries independently quoted counterpart row,
period header and unit evidence, cross-bound to the writer's exact source pages
and retained amount. Every counterpart page needs a literal coverage link: either
its printed page label falls within an explicit scope page range, or an explicit
qualification of that exact table/column appears on the same source page. The
model judges the table/column and assurance meaning; Python checks the literal
quotes, page membership, value, period and unit identities. A summary elsewhere in
the document cannot inherit assurance solely from the same entity and year. The
original observation may serve as its own counterpart when this complete chain
covers it. Missing evidence stays unknown, subject to independent review.
The same contract is enforced on accepted records, resumed batches and aggregate
approval. Older boolean-only approvals and old request-capacity splits expire;
raw observations, source text and calculations remain unchanged. The smaller
three-target batches bound the additional proof output without trimming sources.
Source discovery uses the configured simple-task reasoning reduction for navigation.
Both `AuditScopeDraft` and `AuditScopeReview` preserve provider-default reasoning
for literal evidence binding and substantive assurance review. The reviewer
searches all supplied original tables and notes
for exact counterparts before accepting unknown status. A summary outside the
covered range does not preclude a covered counterpart elsewhere. Both audited
and unaudited evidence must be assessed, with qualifiers bound to their actual
table and period column. Unsupported derived/adjusted measures remain unknown.
The strengthened review contract expires prior approvals and failed checkpoints
for fresh review, retaining their original audit history. Provider-default opt-out,
exact endpoint/model capabilities, unchanged full source pages and every semantic
and Python proof check remain mandatory. Output limits and retry budgets are unchanged.
Capacity failures have a separate hash of the route, report model, exact operation
policies, temperature, privacy setting and fixed output limits. A changed or
missing capacity identity expires old truncation-based subdivisions, while
completed approvals retain their original source fingerprint and must pass the
current proof checks. Accepted child batches are reused directly even when the
old parent split no longer applies; only remaining target IDs are scheduled.
That resume partition is not recorded as a newly proven capacity failure.
Capacity-only changes preserve completed source approvals for strict reuse;
semantic review-contract changes require a fresh review instead.

Neutral slide headings cannot describe only one comparison's period when other
visible charts cover a wider scope. The Data Index uses the audience topic names
and measured row heights while preserving units, periods and source pages. It
remains before the closing slide.

Summary targeted repair retains all accepted source ownership. Corrections must
partition only the requested inclusive line ranges; facts crossing a boundary
cannot be clipped or silently accepted.

Extraction and arithmetic contracts remain extraction-v23 and analysis-v88.
