# Retained copy checkpoint repair

Local page corrections select numbered sentence spans and return replacement
copy. Python supplies the original offsets; the writer need not transcribe the
old sentence. Exact, unique before/after spans remain compatible with older clients.
Python merges them against the supplied immutable draft and checks the complete
field length and existing source contracts. A span, length or binding failure
shares one correction request; valid sibling pages stay frozen. Complete page
responses remain compatible with older clients. Earlier source-review questions
travel with the rejected draft so a later correction can preserve material
qualifications. Questions never carry approval.

A selection/planning retry preserves its exact findings only when document,
profile, observations, tasks and calculation results are identical and the
current source-context fingerprint matches. A retained selection is structurally
checked again before compilation; final publication review still runs.
When publication review accepts the selection but rejects individual pages,
its explicit retry edits only those pages using the existing correction budget.
Frozen pages need not be serialized through another full-selection response.
The complete final publication review still runs after compilation.
An introduction failure also preserves a source-matched completed analytical
selection; the compiler and introduction checks still run on the next attempt.

Literal context quotations can bind complete calendar dates of attributed
source events. This does not authorize prose-only amounts, new companion rows,
calendar expansion of fiscal labels, or a different measurement population.
The compiled plan rechecks quotation provenance before using these identities.
Exact quotations may also support source-attributed qualitative effects without
inventing measurement endpoints or intervals. Preserve the actual effect and its
literal timing, rather than reducing it to a generic factor or adverse context.
An attributed management judgment needs its own faithful scope and the material
counterpoint; it cannot become an objective judgment about a broader population.
Literal day-count parameters in a complete calculation definition can appear in
that method description. Exact phrases are checked against the quoted source;
they cannot become arbitrary measurements, currencies or altered day counts.
Source-attributed compound noun shapes remain qualitative context, while bound
metric comparisons, explicit values, rates and unknown dates keep normal numeric
validation. Ambiguous-direction diagnostics identify the exact failing clause
and token location instead of only a word that may occur several times.
Complete bound metric names containing “net” remain valid; a bare “Net declined”
claim still fails.

The initial briefing meaning review includes every parseable item, including
items whose numbers need source repair. This exposes material companion context
before the full-item patch, rather than discovering a missing value after the
meaning-only quantity lock takes effect. Source-invalid items cannot acquire a
lock through semantic acceptance.

A meaning correction that adds a complete, exactly quoted flow period at an
already displayed standalone closing date remains rejected. It may use the
existing single contract retry to remove that new period wording. New years,
unquoted durations, altered original flow durations and unrelated counts do not
gain this retry. The corrected brief still needs source and fresh meaning checks.
If a rejected meaning patch requires new source values, an explicit retry returns
to the complete item source-patch route rather than repeating a locked text edit.
Retry feedback merges failed whole-brief and selected-subset verdicts instead of
discarding one when another is present. Final meaning questions retain their
selection-to-original item mapping; older flat verdicts remain unbound questions.
No retained question carries approval or supplies a source value.
A briefing retry retains the primary retrieval order only when its complete
reporting-environment fingerprint matches and the appended companion pages prove
the original retrieval boundary. Otherwise it selects sources afresh. This
prevents incidental retrieval changes from invalidating a repairable draft;
source, topic-coverage and fresh independent meaning gates still run.
Bounded overlength corrections include Python-measured copy lengths and the
reduction to a shorter target. The model can remove secondary history while
retaining material qualifications; Python never truncates or approves prose.
An overlong source addition jointly owned by several included checks may use an
available split slot. Both parts retain its original evidence, every owner gains
the new audience index, and all source dispositions undergo independent review.
Locked numeric structures, the total item capacity and correction budget remain.
On an explicit retry, a source-matched, structurally valid proposal at full
capacity can edit all rejected included sections in place. Omitted sections or
unused capacity still require normal planning. Every section is reviewed afresh.
Source-copy compression retains provider-default reasoning because selecting
secondary facts and preserving qualifications is a semantic editorial task.
Dense qualifications can use the existing literal-evidence comparison table.
A complete targeted patch with overlong/nonrectangular table cells can spend its
single format/copy correction on that same patch schema. Other schema failures
and truncated envelopes stay terminal; a second invalid response cannot loop.
All corrected table cells still need exact quote validation and fresh review.
Table cells may select premeasured physical-page line ranges with @cell references.
Python restores only the continuous original text, normalizing whitespace for the
cell, and checks the 180-character limit and coverage by that item's own literal
quotations on the same page. Unknown, overlong or unowned ranges fail; legacy
literal cells continue through the existing source validator. These references
provide no semantic verdict and cannot add a source or execute document content.
The targeted response schema enumerates premeasured cell references. A shared
format correction freezes structurally valid sibling items and requests only
failed keys, avoiding regressions from rewriting already fitting copy. Copy
compression receives prior rejected questions, never prior approvals, and keeps
the original complete-source and publication gates.
New cell choices use continuous source clauses across PDF line wrapping, with
short directory previews and exact character-span references. Complete numeric
groups and date tokens remain intact. Python restores the full source phrase;
the preview cannot become a quotation. Independent review receives the visible
body and table together and still rejects ambiguous or incomplete conditions.
Dense copy-format patches request only failed fields. An overlong body uses up to
three model-written sentences of at most 150 characters each; Python joins them
without truncation, yielding at most 452 characters. Unrequested copy and tables
stay frozen, and a requested evidence table cannot be discarded into prose.
Local copy requests receive the complete source pages of their owning checks.
The full reporting context is not mutated, and final independent review still
reads every selected check's full source. Unknown or incomplete ownership cannot
reduce the copy context. Existing tables remain required during their repair.
Cell ownership uses the existing continuous-quotation merger: adjacent chunks
can jointly cover a source phrase only when their entire union is literal on the
same page. A gap containing omitted source words still fails ownership.
During source integration, explicitly selecting a premeasured source phrase can
bind its containing original paragraph on an already literally cited page. The
paragraph is restored without changing source text, replacing only quotations
fully contained within it and retaining the six-quote capacity. Fabricated page
ownership, unlisted ranges or excess evidence capacity cannot gain this binding.
The complete published claim and restored context still undergo fresh review.

After supplementary source integration, retained reports measure their complete
native slide cost. If they exceed a user cap, the model may omit whole displayed
findings with source-aware reasons. Kept copy, introduction, briefing, raw data
and calculations stay unchanged. Python validates IDs and projects the subset;
only rebuilt native output proves fit. The final source reviewer independently
judges all retained pages and every omission with the measured budget and existing
audience context. A fitting subset never inherits publication approval.
A physical-budget retry may retain an unchanged, source-complete published brief
only when its full selection inputs, original source, plan and source-review
fingerprint still match. Stale or failed reviews cannot gain this reuse.

A final retained-source rejection can edit only its rejected analytical pages
while preserving the completed briefing, verified introduction, accepted pages
and measured selection. This reuse requires the same original inputs, identical
non-analysis slides and current source-integration fingerprint. Numeric input
IDs cannot be removed during the local edit. New companion references must be
explicitly selected from the same eligible source tables and pass the complete
numeric and citation validators; extracted records and calculations never change.
A failed edit returns the last complete
checkpoint; a successful edit still requires the normal independent final source
review and native page-budget checks before export.
Each completed independent review can supply a new bounded correction; the same
consumed review cannot authorize repeated edits without a fresh source verdict.
Native chart-share preparation preserves exact source-authored retained copy
with current input fingerprints and literal bindings, leaving source-only
qualitative proportions to that mandatory semantic gate. It still validates
numeric claims and slide evidence. Literal attributed period scopes are preserved
whether the attribution precedes or follows the scope in the same sentence.

A failed introduction-reading format repair can use the existing final source-read
slot with the original numbered source lines. It cannot accept changed repair
content or invent missing quote boundaries. Privacy, provider and truncation errors
do not gain that reread; the complete binding and line-coverage gates remain.

Regression tests cover exact spans, immutable siblings, bounded correction,
context-event dates versus unbound amounts, complete metric names versus vague
net claims, initial source-invalid review and period-removal feedback. Optional
private diagnostic fixtures run through environment variables without committing
source documents, extracted content or model credentials.
