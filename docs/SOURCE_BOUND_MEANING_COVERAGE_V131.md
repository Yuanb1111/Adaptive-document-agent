# Source-bound introduction meaning coverage (v131)

A compact introduction could list categories or series names while omitting the
source characteristics that distinguish them. An independent reviewer sometimes
accepted that incomplete paragraph, then rejected it after an unrelated revision
caused the shared paragraph to be reviewed again. Source and numeric validation
could not detect this qualitative omission. More retries would not address the
inconsistent coverage definition.

For an introduction selected under a whole-file slide budget, the model now
specifies the essential meanings within every included source part, each with an
exact quotation owned by that part. The existing independent selection reviewer
checks both selection relevance and completeness of these essential meanings
against the full reading. Detailed table cells and examples are not automatically
made mandatory. All original source parts, roles, pages and raw values remain.

The author, targeted repair and independent meaning reviewer receive the same
stable requirements. Each requirement has a separate covered/missing verdict and
a literal quotation of the actual visible paragraph supporting acceptance. Python
requires every exact index once, rejects a missing item even when the overall
part verdict says accepted, and checks quotations against the complete paragraph
union bound to that part, including appendices and exact continuations. Source
quotations, speaker notes and copy bound to another part cannot substitute for
visible coverage.

Accepted-part reuse includes this contract in its evidence/copy signature. Export
rechecks the contract digest, per-meaning verdicts and actual visible quotes along
with the existing independent review and copy digest. Old selections lacking the
contract cannot silently reuse completion. The analysis and pipeline versions are
updated; extraction remains unchanged.

The existing numeric, source, privacy, semantic repair and physical slide budgets
remain mandatory. No product names, source keywords, document types or special
numeric exceptions select a production workflow. Models choose semantic meaning
through `LLMGateway`; deterministic checks only enforce evidence ownership,
coverage inventory, exact-copy binding and existing calculations.

The audience selection and author also receive a readable prose target scaled to
the introduction cap. Layout correction reports the measured physical pages,
paragraph labels and copy sizes, including sparse continuations caused by logical
group boundaries. The model can combine meanings and groups concisely; Python
still checks actual geometry. Neither raw source clipping nor extra layout/meaning
attempts are introduced. The full table evidence remains in analysis/data exports.

Live validation also exposed monetary comparison metadata that prepended a
currency/scale to a bare table cell. The briefing reviewer now explicitly returns
the literal signed coefficient with the original complete table passage carrying
its headers, rather than manufacturing a contiguous money quotation. Existing
unit, coefficient, sign, direction and duration validators remain unchanged.

Required meanings are independently checkable assertions, rather than whole
paragraphs bundled into a single long checklist sentence. A measure stays with
its necessary period, basis and attribution. Cross-paragraph source ownership is
explicit: where faithful copy already exists, repair its source bindings while
retaining that copy and its existing citations, instead of duplicating it.

Invalid quoted reviewer copy or an incomplete coverage inventory belongs to the
existing bounded review-protocol correction against the same source and same
draft. It must not cause the author to rewrite already valid paragraphs merely
to match a reviewer paraphrase. A genuinely missing meaning still enters the
unchanged semantic repair limits and can never pass through a formatting repair.

Regression coverage includes contradictory overall/individual verdicts, missing
and duplicate indices, another part's visible copy, appendix coverage, stale or
unowned contracts, author/reviewer consistency and source-preserving export.
