# Visible paragraph coverage review (v157)

The v156 `.001` failure reached semantic introduction review, after successful
reading and calculations. Its Chinese draft already contained the listing
basis, unmet listing-rule requirements, losses, operating cash use and dividend
conditions. The initial independent review accepted those meanings but quoted
English PDF evidence instead of current Chinese copy. The protocol repair then
rejected the same meanings as absent. A content revision returned the existing
correct paragraphs and failed the unchanged-draft guard.

Coverage requests now include exact visible paragraphs grouped by their bound
source part, with stable paragraph IDs. Reviewers can select those IDs instead
of retyping/translating quotations. Python binds the selected literal text; the
model still decides semantic coverage independently. Unknown, duplicate and
other-part addresses are rejected. Exact continuations are reconstructed without
lending one fragment's source ownership to another. Saved address-based reviews
are checked again against current visible text and ownership at export.

Legacy literal-quote verdicts remain supported under the existing strict
quotation checks. When a quote-only protocol failure is followed by a changed
semantic verdict on the unchanged text, one final independent visible-copy
review resolves the disagreement. This third review is reserved for that exact
transition. It can confirm rejection; it does not approve author references or
force acceptance. Ordinary genuine omissions retain the existing content repair
path. Repeated protocol failures still stop after two calls. The unchanged-draft
guard remains active.

Coverage protocol diagnostics collect every affected part rather than stopping
at the first quotation mismatch. Terminal introduction failures distinguish
semantic review from content repair and retain the rejected source page IDs.

Pipeline advances to v157 and analysis to `analysis-v81`; extraction remains
`extraction-v22`. Restart the app and run the source PDF again. A saved v156
checkpoint does not automatically gain a new independent semantic verdict.

Tests cover cross-language source/visible quotation confusion, bounded verdict
disagreement review, genuine omission rejection, wrong/duplicate addresses,
current-copy tampering, exact continuation ownership and failure-stage location.
Private source files and replay fixtures stay outside Git. Synthetic or
retained-response replay is distinct from a new live provider verdict.
